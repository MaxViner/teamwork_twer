# Local Video Evidence

Локальный сервис извлечения признаков места съёмки из видео:
подготовка превью, метаданные и GPS, сцены, речь, OCR, повторы,
объекты сцены, визуальный профиль, звуковая структура, геометрия
дороги и итоговое локационное досье.

## Запуск

```bash
pip install -r requirements.txt
# требуются: ffmpeg и ffprobe в PATH
# exiftool не обязателен: метаданные MP4/MOV читаются без него

python -m app.main
# либо: uvicorn app.server.server:appServer --reload
```

## Что извлекается для поиска места

- GPS и теги контейнера MP4/MOV, дата и модель устройства;
- адреса, координаты, телефоны, домены, бренды, валюты,
  номерные знаки и особые буквы в речи и надписях;
- упоминания городов, районов и объектов в тексте;
- визуальный профиль: освещённость, погода, сезон, ландшафт;
- объекты сцены (SegFormer, при недоступности — эвристики);
- геометрия дороги и разметка;
- звуковой фон: тишина, громкость, низкочастотный гул;
- повторяющиеся надписи и визуально похожие кадры.

Итог — проверяемое локационное досье с координатами,
странами и местами-кандидатами и поисковыми запросами.
Это гипотезы, а не подтверждённый адрес.

## Структура

- `app/main.py` — точка входа приложения
- `app/server/server.py` — FastAPI-приложение и HTTP-эндпоинты
- `app/pipeline.py` — порядок и запуск этапов анализа
- `app/jobs.py` — хранение и изменение заданий
- `app/stages/` — этапы анализа
- `app/geo.py` — извлечение и объединение географических признаков
- `app/media/` — работа с контейнерами, кадрами и ffmpeg
- `app/reporting.py` — Markdown-отчёт
- `app/models.py` — Pydantic-модели
